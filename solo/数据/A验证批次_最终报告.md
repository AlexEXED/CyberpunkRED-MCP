## 五、踩坑记录

| # | 坑 | 修复 |
|---|-----|------|
| 1 | MD分隔线 `---------` 被正则误解析为数据行 | 后处理过滤 `^[-—]+$` |
| 2 | Markdown `**加粗**` 残留 | `replace('**','')` 清除 |
| 3 | MCP text_value 缺少 `"type":"text"` → 插入失败 | 生成器强制添加 |
| 4 | MCP 空字符串 `""` → -32603 错误 | 用空格 `" "` 替代 |
| 5 | 插入时空格在云端trim后diff误报 | normalize 统一处理 |
| 6 | 批次失败从头部重试 → 前序数据重复 | 需加幂等检查 |

## 六、流程改进建议

1. **插入前去重**：每次 add_records 前先 list_records 检查已存在记录
2. **批处理幂等**：失败后从断点续传，不从头部开始
3. **创建后清理**：SmartSheet创建后立即删除自动生成的空行
4. **规范目录结构**：parse_output/ 只保留规范数据和最终批次文件
